# My Notes (Personal Workspace)

Use this folder for your own notes, experiments, and completed exercises. Everything inside `My_Notes/` (except this `README.md`) is ignored by Git so your work won't clash with weekly lecture updates.

## Weekly Workflow

1. **Pull the latest lecture:** At the start of class, open **Source Control** in VS Code and click **Pull** (or run `git pull`) to download the new folder in `lectures/`.
2. **Copy the lecture folder here:** Copy the entire weekly folder (for example, `lectures/01_Lecture`) and paste it into `My_Notes/` so any local data files or images stay linked.
3. **Work inside `My_Notes/`:** Open the copied notebook inside `My_Notes/`, take notes, and run code there. Leave the files inside `lectures/` untouched.

> **Important (PC Pool Reminder):** Because `My_Notes/` is not pushed to GitHub, back up your work (e.g., to cloud storage or a USB drive).
